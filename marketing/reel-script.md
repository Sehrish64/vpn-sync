# 🎬 Instagram Reel Script (30 sec, Roman Urdu)

**Hook (0-3s)**, screen pe VPN on, bade text mein:
> "VPN laga ke sochte ho tum chhup gaye? 😏 Ye website tumhe 10 second mein pakad legi."

**Scene 1 (3-10s)**, `demo/index.html` kholo, button dabao:
> "Dekho, VPN on hai. IP Germany ki hai. Lekin..."
Result: **"4/5 se pakda gaya 🚨"**
> "Timezone Karachi ka, language bhi Pakistan ki. VPN ne sirf IP badli, baqi sab bol gaya."

**Scene 2 (10-20s)**, `chrome://extensions` mein `vpn-sync` load karo:
> "Ab ek extension lagata hoon, vpn-sync. Ye browser ko VPN ki country jaisa bana deta hai."

**Scene 3 (20-27s)**, dobara check chalao: **"0/5, Stealth grade A+ ✅"**
> "Ab dekho, ghari, zubaan, sab match. Website ko lagta hai main Germany ka hoon."

**CTA (27-30s)**
> "Free hai, GitHub pe. Link bio mein. Apna score comment karo! 👇"

**Caption:**
> VPN lagane se bhi pakde jaate ho? 🕵️ Apna score comment karo. #vpn #privacy #github #coding #pakistan

## Tips
- Vertical 9:16, bade font ki subtitles
- "Pakda gaya" pe buzzer sound, A+ pe "ding"
- Pehle 3 second mein result ki jhalak dikhao
- "100% undetectable" mat bolo, "pakde jaane ke chances kam" bolo
- Reel mein wohi score dikhao jo asli test mein aaya
